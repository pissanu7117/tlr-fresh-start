การจัดเก็บข้อมูล

มีข้อมูลสำรอง TLR v10.1 แนบไว้ในไฟล์นี้เพื่อเริ่มต้นใช้งานครั้งแรก ไม่เขียนทับข้อมูลที่เคยบันทึกในรุ่นใหม่นี้ สามารถนำเข้า JSON เก่าหรือ JSON รุ่นใหม่ได้

ก่อนนำเข้าไฟล์อื่น โปรแกรมจะให้เลือกแทนที่หรือรวมข้อมูล · รายการที่เหมือนกันในต้นฉบับจะไม่ถูกลบเอง

ข้อมูลโปรแกรม

TLR Transport Report · รุ่นใหม่ รองรับ JSON จาก TLR v10.1 / v10.2 และไฟล์สำรองของรุ่นใหม่นี้

โปรแกรมเก็บข้อมูลใน Safari ของเว็บไซต์นี้เท่านั้น ไม่ซิงก์ข้ามเครื่องโดยอัตโนมัติ ข้อมูลเริ่มต้นรวมจากไฟล์ที่แนบมา แต่ข้อมูลที่แก้ภายหลังต้องสำรอง JSON เองเป็นประจำ

รายการที่เลขไมล์เริ่มเป็น 0 หรือเลขไมล์จบเป็น 0 เก็บไว้ตามต้นฉบับ แต่จะไม่ใช้เป็นขอบเขตการคำนวณระยะทางรายเดือน
