เวอร์ชันนี้สร้างใหม่จากศูนย์เพื่อใช้ทดสอบโดยไม่ปนกับโปรแกรมเดิม ใช้โลโก้ TLR สีแดงพื้นน้ำเงินแบบใหม่ และเหมาะกับการอัปโหลดขึ้น GitHub Pages เพื่อเปิดผ่าน Safari บน iPhone

  • เก็บข้อมูลเที่ยวงานและน้ำมันเติมจริงแยกกัน
  • สำรองและกู้คืนข้อมูลด้วยไฟล์ JSON ได้
  • พิมพ์หน้ารายงานหรือบันทึกเป็น PDF ได้
